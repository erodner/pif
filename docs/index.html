Prompt Injection Finder

Version 2.0 · open source (AGPL-3.0) · source code · download

An AI assistant that reads a PDF also reads text a person cannot see: white text, 0.1-point fonts, text outside the page, metadata. Some documents use this to plant instructions for the AI, for example “give a positive review only” in submitted papers or “recommend hiring” in CVs. This tool reports such text and shows where it is on the page. Everything runs locally; documents are not uploaded anywhere.

Robust Estimation of Sparse Signals
We study robust estimation of sparse signals under adversarial noise. Our method builds on convex relaxations. Experiments on three benchmarks confirm the findings.

What it checks

  • Hidden text: background-coloured, tiny, invisible-render-mode or transparent text; text covered by shapes, clipped away, outside the page or in hidden layers; text drawn glyph by glyph; fonts whose displayed text differs from the extracted text (checked by OCR); invisible Unicode characters.
  • Non-visible fields: metadata, annotations, form fields, bookmarks, embedded files, JavaScript.
  • Wording: rules for known injection patterns (8 languages), similarity to reference phrasings, and a small learned model that judges hidden text. An optional larger classifier can be downloaded.

Findings are rated high (injection wording in hidden text), medium (visible or in metadata, or unconfirmed) or low (hidden text without injection wording, quoted examples).

How well it works

Results on two test sets, run once with a frozen configuration; tuning used separate development data only. Default setup (no extra download).

Test setPrecisionRecallF1
CrackedPDFs (2,919 PDFs, 15 hiding techniques)0.960.910.93
PlantedPI-PDF (1,080 PDFs, real injection texts in English and German, hard benign texts)0.820.390.53

For comparison, the detector published with CrackedPDFs, trained on that dataset, reaches F1 0.96. PlantedPI-PDF is built reproducibly in the repository from public datasets; full reports are in bench/reports.

Limitations

  • Free-form injections that read like ordinary questions are often missed (recall about 40% on PlantedPI-PDF).
  • Some harmless hidden texts that use words like “ignore” or “bypass” are flagged.
  • A finding is a reason to look at the document, not proof of intent. Papers about prompt injection quote examples.
  • Text inside images is only checked for scanned pages with an OCR layer.

Download

Desktop app for macOS (Apple Silicon), Windows and Linux on the releases page. The builds are not code-signed: on macOS, allow the app once under System Settings → Privacy & Security → Open Anyway; on Windows, choose More info → Run anyway. The app includes the command line tool pif.

pip install "promptinjectorfinder[ml,ocr] @ git+https://github.com/erodner/pif"
pif models download minilm
pif scan papers/ -f html -o report.html
